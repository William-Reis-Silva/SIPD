# 06.1.4 — Catálogo

> Sistema Inteligente de Programação de Discursos (SIPD)

**Versão:** 1.3

---

# Objetivo

Este documento especifica os Casos de Uso relacionados ao módulo de Catálogo do SIPD.

O módulo é responsável pela manutenção e consulta da base global de Temas e Categorias utilizada pelas congregações.

O Catálogo constitui uma fonte compartilhada de informações do sistema e deverá manter os dados oficiais utilizados nas programações.

# UC-CAT-001 — Consultar Temas

## Objetivo

Permitir que usuários autorizados consultem os temas disponíveis na base global do SIPD.

## Atores

- Usuário

## Permissões

Todos os perfis autenticados.

## Gatilho

O usuário acessa o Catálogo de Temas ou realiza uma pesquisa durante o cadastro de uma programação.

## Pré-condições

- Usuário autenticado.
- Existência de temas cadastrados na base global.

## Fluxo Principal

1. O usuário acessa o Catálogo de Temas.
2. O sistema apresenta os temas disponíveis.
3. O usuário poderá pesquisar por número ou título.
4. O sistema apresenta os resultados correspondentes.
5. O usuário poderá consultar os detalhes de um tema.

## Fluxos Alternativos

### FA-01 — Pesquisa sem resultado

O sistema informa que nenhum tema corresponde aos critérios informados.

## Fluxos de Exceção

### FE-01 — Falha ao consultar catálogo

O sistema informa que não foi possível carregar os temas.

## Pós-condições

Nenhuma alteração é realizada no catálogo.

## Regras de Negócio Relacionadas

- RN-040
- RN-041
- RN-042
- RN-043

## Entidades Envolvidas

- Tema
- Categoria

## Casos de Uso Relacionados

- UC-CAT-002
- UC-CAT-004

## APIs Relacionadas

- GET /temas
- GET /temas/{id}

## Telas Relacionadas

- Catálogo de Temas
- Seleção de Tema

## Observações

A consulta deverá permitir localização rápida dos temas, principalmente durante a criação de uma Programação.

# UC-CAT-003 — Cadastrar Tema

## Objetivo

Permitir o cadastramento de um novo tema na base global.

## Atores

- Administrador Global

## Permissões

- Administrador Global

## Gatilho

O Administrador Global seleciona a opção Novo Tema.

## Pré-condições

- Usuário autenticado.
- Usuário possui perfil Administrador Global.

## Fluxo Principal

1. O Administrador Global acessa o cadastro de temas.
2. Informa o número do tema.
3. Informa o título.
4. Seleciona a categoria.
5. Solicita o cadastro.
6. O sistema valida os dados.
7. O sistema verifica a existência do número.
8. O sistema registra o tema.
9. O sistema confirma o cadastro.

## Fluxos Alternativos

### FA-01 — Número já cadastrado

O sistema informa que já existe um tema com o número informado.

O cadastro não é realizado.

### FA-02 — Categoria inexistente

O sistema solicita a seleção de uma categoria válida.

## Fluxos de Exceção

### FE-01 — Dados inválidos

O sistema informa os campos que precisam ser corrigidos.

## Pós-condições

Um novo Tema passa a fazer parte da base global.

## Regras de Negócio Relacionadas

- RN-040
- RN-041
- RN-042
- RN-043

## Entidades Envolvidas

- Tema
- Categoria

## APIs Relacionadas

- POST /temas

## Telas Relacionadas

- Novo Tema
- Catálogo de Temas

# UC-CAT-004 — Editar Tema

## Objetivo

Permitir que o Administrador Global corrija ou atualize os dados de um tema.

## Atores

- Administrador Global

## Permissões

- Administrador Global

## Gatilho

O Administrador Global seleciona um tema e solicita sua edição.

## Pré-condições

- Tema existente.
- Usuário autenticado.
- Usuário possui permissão de administração do catálogo.

## Fluxo Principal

1. O Administrador Global seleciona o tema.
2. O sistema apresenta os dados atuais.
3. O Administrador Global altera os dados necessários.
4. Solicita o salvamento.
5. O sistema valida as alterações.
6. O sistema registra a alteração.
7. O sistema confirma a operação.

## Fluxos Alternativos

### FA-01 — Nenhuma alteração

O sistema informa que não existem alterações a salvar.

## Fluxos de Exceção

### FE-01 — Dados inválidos

O sistema rejeita a alteração e informa os dados que precisam ser corrigidos.

## Pós-condições

Os dados do Tema são atualizados na base global.

A alteração deverá permanecer registrada no Histórico.

## Regras de Negócio Relacionadas

- RN-040
- RN-041
- RN-042
- RN-043
- RN-102

## Entidades Envolvidas

- Tema
- Categoria
- Histórico

## APIs Relacionadas

- PUT /temas/{id}

## Telas Relacionadas

- Editar Tema
- Catálogo de Temas

# UC-CAT-007 — Importar Catálogo S-99

## Objetivo

Permitir que o Administrador Global importe ou atualize a base de Temas e Categorias a partir da relação oficial S-99.

## Atores

- Administrador Global

## Permissões

- Administrador Global

## Gatilho

O Administrador Global solicita a importação ou atualização do catálogo.

## Pré-condições

- Usuário autenticado.
- Usuário possui perfil Administrador Global.
- Arquivo ou fonte oficial disponível.

## Fluxo Principal

1. O Administrador Global inicia a importação.
2. O sistema recebe os dados do catálogo.
3. O sistema valida a estrutura dos dados.
4. O sistema valida números e títulos dos temas.
5. O sistema valida as categorias.
6. O sistema identifica novos registros.
7. O sistema identifica registros existentes.
8. O sistema apresenta o resultado da validação.
9. O Administrador Global confirma a operação.
10. O sistema atualiza a base global.
11. O sistema registra a operação no Histórico.

## Fluxos Alternativos

### FA-01 — Nenhuma alteração encontrada

O sistema informa que o catálogo já está atualizado.

### FA-02 — Existem registros novos

O sistema apresenta os registros que serão adicionados.

## Fluxos de Exceção

### FE-01 — Estrutura inválida

O sistema interrompe a importação e informa o problema encontrado.

### FE-02 — Dados inconsistentes

O sistema apresenta os registros que não puderam ser processados.

## Pós-condições

A base global de Temas e Categorias é atualizada somente após validação e confirmação da operação.

## Regras de Negócio Relacionadas

- RN-040
- RN-041
- RN-042
- RN-043
- RN-102

## Entidades Envolvidas

- Tema
- Categoria
- Histórico

## APIs Relacionadas

- POST /catalogo/importar

## Telas Relacionadas

- Importar Catálogo
- Catálogo
- Resultado da Importação

---

# Considerações Finais

O módulo de Catálogo mantém as informações globais utilizadas pelo SIPD.

Os Temas e Categorias não pertencem a uma congregação específica.

A administração da base global é responsabilidade do Administrador Global, enquanto os demais usuários possuem acesso para consulta conforme suas permissões.

O módulo de Catálogo não administra Temas Preparados. Essa responsabilidade pertence ao módulo de Oradores.
