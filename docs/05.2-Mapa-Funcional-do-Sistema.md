# 05.2 - Mapa Funcional

> Sistema Inteligente de Programação de Discursos (SIPD)

Versão: 1.1

---

# Objetivo

O Mapa Funcional apresenta a organização funcional do SIPD sob a perspectiva do usuário.

Seu objetivo é identificar todas as áreas do sistema, seus módulos e funcionalidades, servindo como ponte entre o Modelo de Domínio e os Casos de Uso.

Este documento não descreve regras de negócio nem detalhes de implementação. Ele representa apenas a organização funcional da plataforma.

# Organização Hierárquica

O SIPD está organizado em quatro níveis.

```
Sistema
    ↓
Área Funcional
    ↓
Módulo
    ↓
Funcionalidade
```

Exemplo:

```
SIPD

↓

Programações

↓

Convites

↓

Enviar Convite
```

---

# Objetivos do Mapa Funcional

Este documento possui as seguintes finalidades:

- organizar todas as funcionalidades do sistema;
- servir como índice para os Casos de Uso;
- orientar a construção da interface do usuário;
- facilitar a organização da arquitetura do software;
- apoiar a modelagem do banco de dados;
- servir como referência para futuras evoluções do sistema.

---

# Considerações Finais

O Mapa Funcional representa a visão estrutural das funcionalidades do SIPD.

Todas as funcionalidades descritas neste documento deverão possuir um ou mais Casos de Uso específicos.

Este documento servirá como referência para a organização da interface, da arquitetura da aplicação e da implementação do sistema.
