# Sistema Inteligente de Programação de Discursos (SIPD)

## Documento de Visão do Produto

### O que é

O SIPD é uma plataforma inteligente para gerenciamento de programações
de discursos públicos. A primeira versão será uma aplicação web
responsiva (PWA), instalável em celulares e desktops direto do
navegador, com a arquitetura preparada para gerar aplicativos nativos
Android e iOS a partir da mesma base de código, sem retrabalho.

## Missão

Transformar a programação das reuniões em um processo simples, seguro e
inteligente, reduzindo tarefas repetitivas, evitando erros e entregando
ao secretário as informações certas no momento certo.

> **O secretário deixa de procurar informação. A informação procura o
> secretário.**

## Core Value

-   Agendar um discurso em segundos.
-   Automatizar verificações.
-   Orientar decisões.
-   Evitar erros.
-   Manter histórico.

## Princípios

1.  Simplicidade acima de tudo.
2.  Automatizar tarefas repetitivas.
3.  Evitar erros antes que aconteçam.
4.  O sistema orienta decisões.
5.  Compartilhar conhecimento.
6.  Um dado existe apenas uma vez.
7.  Todo evento gera histórico.
8.  Arquitetura preparada para crescer.

## Requisitos

-   Autenticação.
-   Cadastro global de congregações, temas e oradores.
-   Programações.
-   Convites.
-   Confirmações.
-   Histórico.
-   Alertas inteligentes.
