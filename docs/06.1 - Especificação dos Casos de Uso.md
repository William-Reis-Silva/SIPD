# 06.1 - Especificação dos Casos de Uso

> Sistema Inteligente de Programação de Discursos (SIPD)

**Versão:** 1.1

---

# Objetivo

Este documento define o padrão oficial para a especificação dos Casos de Uso do SIPD.

Cada Caso de Uso descreve detalhadamente uma funcionalidade do sistema, apresentando os atores envolvidos, permissões necessárias, regras de negócio, fluxo de execução e resultados esperados.

Este documento complementa o **06 - Casos de Uso**, que apresenta o inventário geral das funcionalidades.

---

# Organização

Para facilitar a manutenção da documentação, os Casos de Uso serão organizados por módulos do sistema.

Cada módulo poderá possuir um documento próprio.

| Documento | Conteúdo |
|-----------|----------|
| 06.1.1 - Administração | Autenticação, usuários, perfis e permissões |
| 06.1.2 - Congregações | Congregações e usuários da congregação |
| 06.1.3 - Oradores | Cadastro, temas preparados, histórico e vínculo de conta |
| 06.1.4 - Catálogo | Temas e categorias |
| 06.1.5 - Programações | Programações, agenda e calendário |
| 06.1.6 - Convites | Convites e confirmações |
| 06.1.7 - Relatórios | Emissão e consulta de relatórios |
| 06.1.8 - Configurações | Perfil e preferências |
| 06.1.9 - Inteligência | Sugestões, alertas, indicadores e dashboard |
