# 06.1.7 — Relatórios

> Sistema Inteligente de Programação de Discursos (SIPD)

**Versão:** 1.2

---

# Objetivo

Este documento especifica os Casos de Uso relacionados ao módulo de Relatórios do SIPD.

O módulo permite consultar e consolidar informações operacionais do sistema, fornecendo uma visão organizada dos dados de programações, oradores, convites e histórico.

Os relatórios são destinados principalmente ao acompanhamento e à tomada de decisão pelos usuários autorizados.

# UC-REL-001 — Consultar Relatórios

## Objetivo

Permitir que usuários autorizados acessem os relatórios disponíveis para sua congregação.

## Atores

- Editor
- Coordenador
- Leitor

## Permissões

Todos os usuários autorizados da congregação poderão consultar os relatórios disponíveis para seu perfil.

## Gatilho

O usuário acessa o módulo Relatórios.

## Pré-condições

- Usuário autenticado.
- Usuário possui acesso à congregação.

## Fluxo Principal

1. O usuário acessa o módulo Relatórios.
2. O sistema apresenta os relatórios disponíveis.
3. O usuário seleciona o relatório desejado.
4. O sistema apresenta os filtros disponíveis.
5. O usuário informa os filtros.
6. O sistema processa a consulta.
7. O sistema apresenta os resultados.

## Fluxos Alternativos

### FA-01 — Nenhum resultado

O sistema informa que não existem dados correspondentes aos filtros utilizados.

## Fluxos de Exceção

### FE-01 — Falha na geração

O sistema informa que não foi possível gerar o relatório.

## Pós-condições

Nenhum dado operacional é alterado.

## Regras de Negócio Relacionadas

- RN-090
- RN-091

## Entidades Envolvidas

- Programação
- Orador
- Convite
- Histórico
- Congregação

## Casos de Uso Relacionados

- UC-REL-002
- UC-REL-003
- UC-REL-004
- UC-REL-005

## APIs Relacionadas

- GET /relatorios

## Telas Relacionadas

- Relatórios

# UC-REL-002 — Relatório de Programações

## Objetivo

Permitir consultar as programações de uma congregação em determinado período.

## Atores

- Editor
- Coordenador
- Leitor

## Permissões

Usuários autorizados da congregação.

## Gatilho

O usuário seleciona Relatório de Programações.

## Pré-condições

- Usuário autenticado.
- Usuário possui acesso à congregação.

## Fluxo Principal

1. O usuário seleciona o relatório.
2. Informa o período desejado.
3. Poderá filtrar por status.
4. Poderá filtrar por tema.
5. Poderá filtrar por orador.
6. Solicita a geração.
7. O sistema consulta as programações.
8. O sistema apresenta os resultados.

## Fluxos Alternativos

### FA-01 — Período sem programações

O sistema informa que não existem programações no período selecionado.

## Fluxos de Exceção

### FE-01 — Período inválido

O sistema solicita a correção dos filtros.

## Pós-condições

Nenhuma alteração é realizada.

- RN-090

# UC-REL-006 — Exportar Relatório

## Objetivo

Permitir que o usuário exporte um relatório gerado para utilização fora do sistema.

## Atores

- Editor
- Coordenador
- Leitor

## Permissões

Usuários autorizados que possuam acesso ao relatório correspondente.

## Gatilho

O usuário seleciona a opção Exportar após gerar um relatório.

## Pré-condições

- Relatório gerado.
- Usuário possui acesso aos dados apresentados.

## Fluxo Principal

1. O usuário gera um relatório.
2. Seleciona Exportar.
3. Seleciona o formato disponível.
4. O sistema prepara os dados.
5. O sistema gera o arquivo.
6. O sistema disponibiliza o arquivo ao usuário.

## Fluxos Alternativos

### FA-01 — Formato não disponível

O sistema apresenta os formatos disponíveis para exportação.

## Fluxos de Exceção

### FE-01 — Falha na geração do arquivo

O sistema informa que não foi possível gerar a exportação.

## Pós-condições

Um arquivo contendo os dados do relatório é disponibilizado ao usuário.

A exportação não altera os dados de origem.

## Regras de Negócio Relacionadas

- RN-091

# Considerações Finais

O módulo de Relatórios possui caráter predominantemente consultivo.

Os relatórios não devem alterar os dados de origem do sistema.

O acesso aos dados deverá respeitar as permissões do usuário e o limite de sua congregação.

O perfil Leitor poderá consultar os relatórios disponibilizados para seu nível de acesso, mas não poderá alterar os dados apresentados.

As informações apresentadas nos relatórios deverão ser obtidas diretamente dos dados registrados no SIPD, mantendo consistência com as Programações, Oradores, Convites e Histórico.
